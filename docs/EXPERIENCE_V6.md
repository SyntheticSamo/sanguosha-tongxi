# v6 · 卡牌到位显示、桌面效果与操作整理

v6源码实现；托管权限和发布状态见[部署说明](DEPLOYMENT.md)。新手教学保持可选。武将、技能及装备范围沿用v5；玩家作发动和选择，系统执行实际效果，房主纠正仍保留。

## 显示与操作

- 新快照渲染前登记待到位牌。手牌槽位先保留空白几何，不包含牌面、详情按钮或可操作控件；飞牌到位的同一帧显示手牌。终点每帧读取实际槽位，随理牌、滚动、视口及角色移动更新。
- 开局按主公起始座次轮流发牌，单张约600ms、间隔200ms、最多同时三张。技能获得逐张到位；其他玩家只收到事件允许公开的牌面。手牌数字始终为权威值，途中数量另标，牌背逐张到位。
- 已移走的待到位牌取消；积压合并或落到最新状态。恢复、重连、撤销不重播；减少动态立即显示到位结果。规则响应不受动画队列阻塞，也不因牌未到位就判为无牌。
- 本人角色、气泡、技能、按钮、手牌共用扣除右侧牌堆后的中轴。自动／出牌／取消／手动紧贴手牌上方，统一高度和宽度；手动关闭朝右、展开朝上。出牌按钮保持简短，目标和牌名由选中状态、卡面及关系线表达。
- 手牌带内拖动理牌，移出后仅显示箭头；触屏短滑滚动、长按拖牌。排序不发送游戏指令，不清空材料或目标。技能材料筛选及私看期间保留真实手牌槽，额外的装备／专属材料另列；未轮到可使用时只读显示。Alt＋左右调整本地顺序；菜单键、Shift＋F10、右键打开手牌菜单，保留排序和详情。
- 移除理牌入口、左右移动按钮及空闲出牌提示。武将势力改为名字左侧的圆形文字标记；化身同步更新。极矮横屏将六格阶段条移入顶栏，并保留回合归属。竖屏响应为下方角色留出空间。

## 关系与展示

关系线使用牌桌局部SVG坐标，每帧跟随锚点。出牌人→牌默认淡显，悬停、聚焦、选中时高亮并流动；牌→作用对象持续有方向虚线。闪连接其响应的杀，无懈连接前序牌。多目标锦囊的抵消按当前目标记录，不把一次无懈画成所有目标都失效。转移、取消及归档有独立结构化字段，不解析日志文本。

真实`pool`仍是内核临时牌区；正常新版流程不显示处理区牌堆或通用面板。旧自由操作工具位于下方折叠区。

`dist/data/card-presentation.js`登记全部44类牌。展示按使用、响应、判定、拼点、公共亮牌和私看上下文分派；不是新增真实牌区或额外牌实例。

| 牌类／上下文 | 展示路径 |

| 五谷丰登 | 桌心公开牌列，当前玩家直接拾取；获得飞到实际手牌槽，剩余牌流向弃牌堆 |

回合结束前捕获旧桌面锚点，展示副本按出牌者飞入记录堆；大量归档每人合并为最多三张并注明总数。真实牌早已在规则结算时移动，归档不再扣牌、不触发失去或获得牌技能。记录仍受每人20条、全桌160条及体积限制。

## 无懈、匿名牌背与判定

- 无懈资格由权威端复用真实响应校验，含手牌、看破、解围、木牛、合法蛊惑及禁用限制。蛊惑不预查真假。每轮及集智等中途效果后重新核对。
- 只向本人投影可反制状态；接收方保留非阻断受影响提示，没有来源时不要求接受效果。其他无牌者同事务静默跳过，不发送资格／放弃名单，不逐人记公开日志。
- 标准规则仍允许第三方替目标反制；没有倒计时。等待时长可能透露场上有人能反制，不承诺消除时长推断。
- 匿名选牌排列由Worker一次洗混，真实ID与映射不投影。点击操作包含窗口及选择编号，不在点击后重新随机。聊天、重连、存档及持牌者本地理牌不重排；真实手牌变化使旧窗口失效。
- 判定先完成适用的无懈窗口，然后`judgeAwait → revealJudge → judge → 确认`。翻判只能由对应玩家对当前窗口提交。判定后阶段令牌要求当前玩家手动继续；自动开关不能清除此门槛。
- 自动开关默认开启，只修改本人当前回合设置，各席位分别保存；仅推进已完成的空阶段，停留至少1.5秒，不自动结束出牌、不代作任何选择。

## 兼容和验证

schema／protocol升为6，客户端需同版本。v1–v5迁移保留原技能／装备范围；旧经典交互保留旧推进和摸牌方式。已翻开的判定继续确认，不重新抽牌；新旧展示均建立恢复基线；旧的全员无懈等待窗口会重新核对资格，无来源时自动继续。底层`newRoom`的`tableExperience`为显式开关，建桌界面启用新版体验，旧测试／嵌入调用可保留旧交互。

最终命令、数量、浏览器场景及限制以[验证记录](TESTING.md)顶部v6条目为准。没有跨互联网NAT/TURN、真实手机后台、Safari/Firefox或全部武将装备组合穷举验证。陆抗固定集智引用的实体印次限制沿用[支持清单](SKILL_AUTOMATION_STATUS.md)。
