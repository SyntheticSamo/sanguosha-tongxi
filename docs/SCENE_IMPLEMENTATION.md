# v3.1 整桌布局与卡牌交互

2026-10-30。本地实现，未推送、未发布到公网。技能收录和自动范围沿用v3，不改变实际牌区和响应规则；schema / PROTOCOL仍为3。

## 布局与操作

- 牌桌占用首屏，自己居下，手牌置于角色下方；其余玩家按真实座次围桌。中央显示轮次、阶段、当前回合及对应阶段按钮。他人回合隐藏推进按钮，需要本人响应时仍可正常响应；房主代推进在下方高级工具。
- 本桌、记录、聊天为同一折叠区，位于牌桌之后的普通文档流。展开增加页面长度，不覆盖或压缩牌桌。房间编号、演练切席、范围详情、理牌和纠正等按需打开。
- 右侧抽牌堆、弃牌堆、处理区厚度按实际数量变化，空堆有轮廓。悬停/聚焦显示计数；触屏可点按。抽牌堆不展示牌面和顺序；公开处理区可以展开选牌，五谷及技能公开选牌会打开此区。
- 每名角色有五个装备槽（含正负坐骑）、延时锦囊判定区、最近公开出牌位和临时判定展示位。最近出牌是只读历史，不是新增牌区，也不能据此取牌。新使用/打出覆盖该角色旧展示；转化显示效果名称，详情列出公开材料；无实体视为牌不创建实例。
- 手牌扇形排列，悬停/聚焦/选中抬起；大量牌横向滚动，首尾都可到达。对手只显示牌背叠及真实张数。瞄准只有箭头，原牌留在手牌；实际飞牌在合法事务提交后播放。
- 手牌、装备提供悬停/聚焦预览，触屏支持长按。特殊牌有独立详情按钮；装备槽也有详情入口，不与选牌或选目标共用按钮。原生详情对话框展示唯一牌库中的规则、装备支持范围和公开转化材料，光标倾斜限制为±8°，触屏/键盘/减少动态模式保持静态。
- 人数为默认4的数字框，校验2–8之间有限整数；2/3人显示非标准身份局提醒。五选一按真实私密候选逐张入场，可跳过或选择已出现候选，同一房间/席位/候选组合重开面板不会重播。
- 新手教学仍默认关闭、可退出和重开；手机以横屏布局优先，竖屏仍可操作。

## 牌区依据

已检索Wiki术语，并以现有规则集镜像核对：公共处理区存在，判定区用于延时锦囊。普通使用/打出的牌不能仅因与某角色相关就改放其判定区。判定动画靠近角色显示，实际卡牌仍按原规则经过处理区。

## 展示数据与私密性

`backend/presentation.js` 在权威事务中收集展示信息；`ui/scene.js` 渲染角色、牌堆、卡牌详情与动画；`ui/table.css` 定义整桌布局。UI仍只发送意图。

- 可选 `cardEvents` 最多64项，权威记录序列化长度限制32,000字符；事件包含唯一编号、rev、来源/目标区域、数量及发生时确定的可见牌面。重洗牌仅公开数量而隐藏新牌序。私密摸牌/交牌仅给相应持有者或接收者牌面，其余席位仅获得数量。未公开拼点和私看区不会成为公共牌面。
- 可选 `lastPublicPlay` 只保存每人最近一次公开使用/打出的效果、材料及目标；不计入守恒牌区。投影逐字段列出，不能用展开对象携带导入文件中的其他字段。
- 原有体力反馈事件继续使用。展示动画与规则队列分离，约200–450ms；大量牌合批，最多同时飞三张并显示总数量，积压时压缩展示。
- 初次加载、切席、恢复和重连建立基线；撤销由权威 `presentationResetRev` 让所有客户端丢弃旧动画、避免把归还手牌当新摸牌。展示字段缺失的旧v3存档可直接加载，不启用额外技能或改变规则。
- 减少动态可跟随系统或手动设置。它不改变操作、出牌成本、求桃、判定确认和任何自动结算结果。

## 本机验证

语法与HTML ID检查通过；108项测试通过，其中9项新增展示数据场景。浏览器使用临时Chrome资料和合成守恒牌局，不连接个人浏览器。

- 原五套脚本覆盖WebRTC、响应恢复、候选私密、拼点、技能分配、拖拽、键盘目标和触摸。
- 新 `browser-scene.mjs` 覆盖2–8人、1440×900 / 1280×720 / 844×390 / 390×844，检查玩家框不重叠、手牌和角色不超界、无横向溢出；底部折叠区展开不改变牌桌宽高。
- 覆盖人数非法输入、牌堆查看、装备隔离、详情按钮不误选牌、预览、倾斜与焦点返回、箭头无卡片拖影、摸弃判动画、五选一不重播、大量手牌首尾滚动、减少动态和撤销基线。
- 截图在忽略提交的 `test-results/`。仅代表本机Chromium验证，未进行Safari/Firefox、实体手机、跨ISP/NAT或TURN测试。
