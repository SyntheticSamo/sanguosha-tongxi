# 全技能结算与第二轮体验改进

目标：玩家只做发动、选牌、选目标等决定，系统完成全部效果。房主纠正仍是事故恢复工具，不是技能的正常流程。新手教学可选。

实施顺序：公共机制 → 剩余技能 → 决策界面 → 权限、私密性及浏览器回归。

1. 用统一的技能决策步骤展示选择要求和已选数量。
2. 按当前步骤列出合法材料，避免在整副手牌中寻找。
3. 在提交前显示缺少材料或目标的原因。
4. 多步技能保留明确的技能名、当前决策者和继续入口。
5. 专属牌区随角色展示，公开牌与本人私密牌分别投影。
6. 化身候选及借得技能提供本人可访问的选择界面。
7. 私看对手手牌只发送给技能决策者，其他席位只看到等待信息。
8. 转换技、限定技、禁用状态及额外回合以状态说明呈现。
9. 自动执行实际效果并写入记录；正常技能界面移除人工步骤。
10. 断线恢复继续当前选择，不重新扣成本或重复播放动作。
11. 阶段跳过与额外回合纳入权威队列，不要求房主推进纠正。
12. 专属牌、暂存牌和扣置牌纳入守恒及死亡清理。
13. 减少动态设置在选将动画进行中生效，不留下不可选候选。
14. 选择界面支持键盘、触屏及手机布局，避免把规则全文常驻牌桌。

机制分组：伤害替代（天香、不屈）；指定目标（流离、奋威、界铁骑、往烈）；专属牌区（明任、征荣、鸿举、屯田、凿险、箜声）；阶段与额外回合（神速、巧变、放权）；精确移动事件（奋激、清俭、良姻、再起、固政）；结算结束与跨回合追踪（替身、恃才、审时、镇骨）；私密声明与动态技能（蛊惑、化身、新生）；其余版本分支（义绝、涯角、救援、勤学、解围、双雄、烈刃、破虏、悲歌、溃诛、贞良、集智、决堰）。

兼容：新增专属牌区及决策内容使用 schema / protocol 4；旧档迁移保持旧技能结算范围，不在进行中的旧局悄然启用新技能规则。界面新建自动桌使用完整结算模式。

验收记录另列实际通过项目；不以覆盖率标签代替分支测试，不把本机联机写成公网验证。

## 本地实现结果

上述14项已接入完整自动模式。选定101将的190个条目有自动处理路径；新增55项场景检查加原108项回归共163项通过，八套浏览器回归通过。具体范围、陆抗临时集智的固定引用口径、装备旧范围与本机验证限制见 SKILL_AUTOMATION_STATUS.md 和 TESTING.md。本轮未发布公网。
