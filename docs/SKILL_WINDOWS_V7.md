# 阶段技能与演练取牌 · v7

新建及恢复的桌面交互桌使用本人阶段技能机会：技能可发动时突出按钮，不再每阶段逐个询问。正常操作成功提交后，关闭对应时机。无效操作不会支付成本或消耗机会；理牌、查看详情、聊天与同步不构成放弃。原经典／手动桌及旧技能、装备支持范围保留。

## 阶段与选择

- 区分阶段前、开始与结束。巧变／神速／放权先于阶段本体，摸牌修正先于第一张正常摸牌。发动前取消返回机会；支付成本后只能放弃规则允许的可选后续。
- 有实际选择时等待本人操作；没有判定内容的巧变、没有实际弃牌要求的巧变不阻止空阶段推进。神速的额外杀仍是实际选择。关闭机会不等于规则意义的跳过阶段。
- 点击抽牌堆开始正常摸牌／判定；阶段开始出现其他强制选择时先完成选择，原出牌不自动代为提交。判定结果确认后仍须手动继续；自动开关不能绕过。
- 受伤、指定目标等瞬时时机保留简短发动／放弃。发动后再展开复杂选择；已主动开启的蛊惑、后续分配与装备响应不再重复询问发动。
- 空材料、空目标不产生不可完成的可选窗口。强制弃牌按实际可弃数量处理；无选择的锁定／觉醒效果直接执行，真实强制分支不能取消。

## 巧变、解围与移牌

移牌与使用装备的规则不同：移动必须放入相同区域的合法位置，不能替换已有同槽装备。判定牌按实际延时锦囊名称检查重复、废除区域与角色限制；转化牌保留原实体与延时名称。[规则：置入与移动](https://gltjk.com/sanguosha/rules/glossary/gamecard.html)、[张郃规则](https://gltjk.com/sanguosha/rules/card/hero/wei.html)。

巧变跳过出牌后可选移牌，也可不移动；没有合法落点则结束此分支。已有成本不退回，阶段仍跳过。预览、高亮和提交使用同一落点检查；换牌清除旧非法目标。旧v6卡住的移牌窗口恢复时刷新合法选择；已经发动的成本不会重新执行。

流离同时按支付武器／坐骑后的距离和攻击范围生成材料与目标组合；无合法组合继续原杀。神速排除空城等不可成为杀目标的角色，无装备成本时不询问对应分支。兵粮／乐已跳过的阶段不再询问第二次跳过，也不执行该阶段的开始／结束技能。

## 演练获得

手牌上方「获得」打开现有牌库。点击获得一张，先取抽牌堆中的真实实例，其次取弃牌堆；剩余数量实时更新，可连续鼠标／键盘操作。关闭恢复焦点。

不复制卡，不取其他角色手牌、装备或专属区，不消耗普通摸牌额度。真实获得触发相关技能并播放入手动画；日志注明演练。开局展示、响应、私看、判定、拼点或实际结算期间不可取牌；普通联机桌没有此工具。

## 协议与兼容

schema／protocol 7。`flow.skillWindow` 保存权威机会及任务，投影仅本人收到窗口编号和技能摘要；内部任务、材料和其他人的机会不广播。新增 `continuePhase({windowId})`，`activateSkill` 接受对应窗口编号；普通操作仍带版本和唯一编号。阶段变化、纠正与撤销使旧任务失效。

`practiceGain({kind})` 在Worker与内核双重校验，只接受本机演练入口；输入牌种而非任意实体ID。网络入口仍仅join／action／sync。

旧档保留技能／装备开关。可安全识别的未发动阶段询问迁移为机会；已公开判定、私看、拼点及付费后续保持当前进度。恢复建立动画基线，不补发牌、不重播历史。
