## 顺序与失败分支

- 回归入口：tests/round-eight.test.js、tests/presentation.test.js、scripts/browser-round-eight.mjs；保留既有规则、完整技能与装备回归。
- 覆盖依赖等待、缺失历史依赖、决策快进、重复ID、非法事务回滚、隐藏牌面、投影对象隔离、连续体力事件、匿名准备期及到位前隐藏。
- 专项内核回归继续覆盖：多张闪、青龙追加与原多目标恢复、贯石成本、寒冰逐次失牌、麒麟与伤害、连环传导／防止、无懈与反无懈、木牛混合材料及离区清理。见 tests/tactile.test.js、tests/round-six.test.js 和 tests/round-seven.test.js。
- 方天的基础复核场景为最后手牌的一次合法使用；不将两人场景写成三目标联动已实测。复杂联动使用既有专门回归。
- 上表的延时锦囊包括实际翻判与确认；武器、防具场景包括安装和一次对应攻击链。基础场景不代表101将、190项技能与44种牌的所有组合已穷举。

## 画面与来源

运行 npm run review:presentations 后打开 http://localhost:4174，可切换全部44种牌，逐步查看真实内核快照、播放／暂停、半速／四分之一速度及展示依赖时间线。页面复用正式 Tabletop、飞牌、关系线和SVG演出，处于只读模式；不属于产品入口，不写入玩家牌桌，不新增联机路由。

关键帧与四尺寸截图生成在 output/playwright/，既有2–8人及装备布局截图仍在 test-results/；两者均为忽略的本地测试产物。具体执行结果与未验证范围以 docs/TESTING.md 的v8.2记录为准。

规则依据沿用 [基本牌](https://gltjk.com/sanguosha/rules/card/basic.html)、[锦囊](https://gltjk.com/sanguosha/rules/card/scroll.html)、[装备](https://gltjk.com/sanguosha/rules/card/equipment.html)、[木牛FAQ](https://www.sanguosha.com/news/20140521_4929_0717) 与 docs/CARD_RULE_AUDIT_V8.md 的版本说明。铁索仍允许单目标；群体锦囊的无懈仍针对当前接收方。动画不改变结算时机。
