# v2.1 易用性实现记录

此页保留v2.1交互重构交付记录；随后v3技能自动化与协议升级已覆盖这里的旧技能范围和版本说明，当前支持以 [技能清单](SKILL_AUTOMATION_STATUS.md) 与 [验证记录](TESTING.md) 为准。

2026-10-29。基于 `229993a`，当前为本地工作区实现；未推送或更新线上托管站点。

新手教学完全可选。首页和牌桌工具均有入口，默认不弹出；可以跳过、退出、重开。在已有牌局中打开只显示提示，不创建新桌，不覆盖当前局。首页启动教学才建立本地演练；演练由使用者切换席位，没有 AI 对手。

## 22 项交付对照

| 01 围桌座次 | 2–8 人围桌布局，本人下方，真实座次不随视角改变；桌面、手机均保留原生玩家按钮。 |

| 04 多目标 | 铁索一或两目标及重铸；借刀持武器者、被杀者分步选择，编号和连线，确认后提交。 |
| 05 智能目标 | 自用与全体牌自动按规则生成目标，清除不相关的旧目标；可拖到桌心使用区。 |
| 06 情境操作 | 合法牌高亮、不可用原因、具体出牌按钮、普通选牌默认单选，弃牌和合法材料可多选。 |
| 07 阶段引导 | 明确下一阶段动作，等待响应、私看区未归还、弃牌未完成时阻止推进。未增加会绕过人工技能时机的自动跳阶段。 |
| 08 摸牌反馈 | 权威摸牌只执行一次，新牌动画与短期标记；明确本阶段已摸或跳摸。手动补摸在高级入口。 |
| 09 弃牌助手 | 显示手牌、上限、需弃、已选和剩余数量；明确克己例外，数量符合要求再提交。 |
| 10 技能范围 | 按武将版本标记自动、主动、部分自动、人工范围；自由手动局明确显示“本桌手动”。技能文本仍来自唯一武将数据。 |
| 11 快捷转化 | 武圣、龙胆、倾国、急救、奇袭、国色，以及丈八、朱雀，直接选择结果和材料；合法响应可自动识别基础转化。 |
| 12 人工步骤 | 技能时机、成本、牌区、目标、执行与完成检查；当前页面保存步骤进度，提供手动工具入口。完成记录不执行第二次效果。复杂技能仍人工裁定。 |
| 13 响应面板 | 杀、决斗、AOE、救援、无懈、判定、拼点、火攻、五谷和目标牌区选择，统一提示与合法响应高亮。 |
| 14 无懈提速 | 默认关闭；显式选择“此席位本局自动放弃”，每个窗口保留三秒撤回；切换席位关闭。没有根据隐藏手牌替其他人推断或放弃。 |
| 15 格子体力 | 实心、空心、数值和可访问描述；上限变化、负体力、濒死所需回复量、阵亡均有呈现。 |

| 17 装备状态 | 武器、防具、坐骑、判定标注；铁索、酒、濒死与阵亡状态；装备自动化范围说明及转换快捷入口。嵌套装备按钮保持目标不变。 |

## 规则和兼容性

- `rules.js` 的纯校验函数同时服务权威提交和 `advisor.js`；前端不另写一套距离、出牌与响应规则。普通投影视图足以生成提示，其他人的手牌仍为 `null`。
- 额外修正：单目标牌不能用重复或多余目标绕过校验；急救材料不能在本人回合当桃主动使用；丈八两张手牌可支付一次杀响应。以上有失败或成功场景测试，失败操作保持原子性。
- 结构化事件字段可选、最多保留 120 项，投影字段显式列出；不传隐藏牌 ID、牌堆次序、token 或私看信息。旧 v2 存档无事件时仍可加载，v1 继续迁移为自由手动；schema / PROTOCOL 保持 2。
- 保持 101 个武将版本和现有牌库，不扩展收录范围；复杂技能没有被宣称为全部自动。没有新增必须安装的运行时依赖、服务器、账号或收费 API。

## 验证

- `node scripts/check.mjs`：23 个模块语法通过，HTML 无重复 ID。
- `node --test`：51 项通过，其中 12 项新用例验证提示与权威一致、双目标视角、转化成本、弃牌例外、事件隐私、伤害事件、旧存档和非法输入。
- `node scripts/browser-smoke.mjs`：四个临时上下文、三个实际 WebRTC 通道，验证自由操作、手牌同步、聊天转义、远端更新取消拖动、刷新恢复、原席位重连、撤销和手机资料库。
- `node scripts/browser-rules.mjs`：真实 WebRTC 下验证五选一私密候选、点击与键盘目标、装备按钮隔离、杀闪、酒、桃、响应中恢复、秘密拼点、判定、纠正、撤销、铁索和借刀。
- `node scripts/browser-ux.mjs`：鼠标拖拽、无效放下、Esc、已选目标、技能转化、响应、血量事件、双目标、无懈提速撤回、可选教学、理牌无副作用、阶段摸牌不重复；2/4/8 人的 1440px 与 390px 布局、无横向溢出、玩家框无互相遮叠；Chromium 触摸拖拽、横向滚动取消、长按详情。
- 桌面、390px、8 人和触摸响应截图已查看。截图保存在忽略提交的 `test-results/`，仅包含临时测试牌桌。

测试使用临时 Chromium 资料，未连接个人浏览器。WebRTC 为同一电脑上的真实通道，不代表异地跨 ISP/NAT 验证；没有 Safari、Firefox 或实体手机实测。仍沿用手动信令交换，受限公网可能需要使用者自配 TURN。

## 本地查看

运行 `node scripts/serve.mjs`，打开 `http://localhost:4173`。现有站点不会因本地修改自动更新。

可选浏览器测试使用 `PLAYWRIGHT_MODULE` 指向可用的 Playwright 模块，`BROWSER_PATH` 指向 Chromium/Chrome；两者仅用于开发验证，不是产品依赖。完整自动化截图均放在 `test-results/`。
