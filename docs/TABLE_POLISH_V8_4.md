# v8.4 · 演出原位、操作区与阶段调试

应用8.4.0，schema／protocol8。延续现有101将、44种牌的规则范围与可选教学；没有新增网络路由、运行时依赖、远端后台或存档版本。发布使用现有GitHub Pages工作流，部署完成需核对Actions结果与线上文件。

## 牌河与铁索

- 牌河固定在牌桌中轴，与本人角色和阶段条对齐。提示窗口不改变中轴；两侧空间决定对称可用宽度，仍按利用空白、增加重叠、最后滚动的顺序排牌。必要时沿中轴使用附近纵向空白并压缩内边距，先保留一张完整牌。碰撞按实际牌面占用高度计算，透明留白不拦截点击，不能因容器留白而把整条牌河推到边角。
- 无懈先到自己的牌河位置，再播放上一效果牌的斜裂与当前无懈的抬起压下。两组展示副本分别锚定各自卡牌，移除旧定位样式与将响应飞向前序牌的特殊终点。反无懈关联前一张无懈。
- 锚点使用牌河当前卡面尺寸、中心和倾斜，滚动、缩放或布局变化时跟随。历史牌不在可见区时隐藏其片段，不移到桌面固定一侧；减少动态及关闭战斗特效沿用静态结果。
- 链条把两端人物框也纳入障碍，从人物边缘选择可达端点；增加中点与偏边缘端点，以适应窄屏装备区。柔化与下垂在生成后再次检查碰撞，不能使已避开的路径穿过人物。
- 铁环沿真实路径切线排列，连接网络仍来自全部存活横置角色。切换本机控制席不改变真实横置状态。保持低透明常驻、状态详情及不拦截操作。

## 主操作与辅助工具

- 原桌心阶段按钮移到出牌左边，只在本人回合出现；继续使用同一规则入口、阶段标签、响应及摸牌／弃牌额度检查。
- 获得、自动开关与手动菜单位于牌桌右下角；竖屏使用窄列，沿用牌堆侧的预留空间。自动开关仍只控制本人当前回合。
- 取消仅在选牌、材料、目标、转化、铁索待用或可取消的本人阶段技能选择时出现。可选阶段技能提交成本前仍可取消；不能借此退出已支付成本后的强制结算。
- 操作栏本身透明、无边框，空白不拦截输入；手牌抬起与按钮按悬停／键盘聚焦切换层级，为抬牌预留容器内空间，避免裁掉上沿。
- 状态徽记放大，本人状态也放在角色上方；装备允许被徽记局部覆盖。布局边界包含状态行，避免顶部状态被裁切。
- 对局日志及出牌记录详情最新在前；可见日志在查看较早内容时保留阅读锚点，筛选后回到最新。展示反序不修改权威日志顺序。

## 撤回上一阶段

「手动 → 撤回上一阶段」为房主设备的调试工具，演练控制席也可使用。它恢复**上一阶段开始**的完整状态，包括手牌、牌堆、技能与等待窗口；不是退回最后一次操作。恢复后版本递增，建立展示基线，不重播历史；桌面交互桌关闭恢复后当前玩家的自动推进，方便检查。

- `phase-history.js`仅保存Worker内存检查点，最多18个且UTF-8序列化总量不超过2MB；单个过大状态不保存。检查点不写入存档、不导出、不发给网络席位。
- 成功进入一个不同阶段时保存基线；聊天、理牌、控制席与阶段内后续操作不覆盖阶段起点。开局发牌展示完成后才建立可用起点。
- 刷新、导入／恢复、普通逐操作撤销和房主纠正后重新建立检查点基线；没有上一阶段时禁用按钮并说明原因，不伪造恢复前的历史。
- 本机专用`rewindPhase`携带操作编号与期望版本，重复请求不重复撤回，过期请求拒绝。完整验证后才提交检查点与状态；清除旧计时和临时整理提示。原有逐操作撤销保留，阶段撤回后清空它的旧分支。
- Worker明确拒绝远端调用所有本机设备接口；网络仍仅join／action／sync。只有本机房主视图含可撤回目标摘要，普通玩家不收到检查点资格或内容。
- 已公开的信息无法让其他玩家遗忘；日志标记为房主调试操作。它不构成竞技回溯或防房主作弊功能。

## 返回主页与昵称

- 演练及联机牌桌顶部均提供「返回主页」。它关闭通道、停止当前设备Worker并回到欢迎页，不删除IndexedDB恢复档或sessionStorage席位凭据。房主离开会中断好友连接；恢复后重新交换邀请，好友保留原标签页可认领原席位。
- 建桌和加入页读取同一个`tongxi:last-name`。仅在成功创建普通牌桌或真正入席后保存当前实际昵称；没变不重复写入。不保存昵称列表，演练与单纯编辑输入框不覆盖最近联机昵称。
- 兼容读取旧`tongxi:guest-name`，下一次实际使用时迁到单值新缓存并移除旧键。浏览器禁止存储时仍可使用当页填写的名字；不同网站来源之间不共享浏览器缓存。

## 验证范围

`tests/table-polish.test.js`覆盖检查点基线、牌区还原、单调版本、过期／重复请求、内存上限、远端权限与私密投影、八方向链条碰撞和单昵称写入。

`scripts/browser-polish.mjs`使用合成牌局、原生输入和临时浏览器资料，检查2–8人、四种尺寸、四人桌各视角、链条边界与人物穿透、无懈／反无懈锚点、主按钮与取消出口、阶段撤回、倒序记录；另通过实际同机WebRTC验证联机返回主页、原席位凭据保留、恢复和昵称持久化。

完整检查、实际结果及截图见 [验证记录](TESTING.md)。本机Chromium、触屏模拟和静态线上文件验证的结论各自独立；本轮未验证跨互联网NAT／TURN、Safari／Firefox或实体手机后台与触控。
