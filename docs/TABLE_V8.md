# 第六轮 · 角色布局、完整回合记录与规则复核

交付范围为本地 v8；不提交、推送或发布。保留101将实体版本、190项技能及可选教学。逐牌审查见 [44种牌对照](CARD_RULE_AUDIT_V8.md)，实际检查结果见 [TESTING.md](TESTING.md)。

## 玩家交互

- 角色名字下为完整身份与昵称。未知身份的个人猜测存本机，按房间、观察席与目标隔离，不进共享快照、存档或导出。公开身份始终优先。
- 势力使用居中的SVG圆标；顶栏为实际距离，本人显示攻击范围；装备是外置五槽，左记录、右判定，手牌数量与体力同一行。装备平时打开详情，材料窗口才可选作材料。所有独立控件不选目标。
- 本人装备、技能、操作按钮、手牌采用同轴短间距。矮横屏与拥挤竖屏将阶段格移入顶栏，中央保留阶段操作与牌。手机竖屏的桌心牌带较窄，横向浏览完整回合记录；窄屏中距离位置变化受碰撞约束，精确数字仍保留。
- 手牌闲置70%，悬停、聚焦和选中100%。正常时机下可双击装备、自用桃酒、无中、闪电及群体牌；稳定牌ID与版本识别同一手势，拖动、响应与材料选择不快捷使用。弃牌显示n/u，超限数字强调，详情保留可访问说明。
- 普通摸牌完成及必要后续结束后，权威端等待约1.5秒进入出牌，无需再点一次，也不受自动开关影响。出牌仍必须手动结束；待判定及其他强制选择不会越过。
- 顺手／过河的手牌选择先洗混1.5秒；匿名编号对应的真实牌在权威端冻结。公开装备与判定可直接选择。持牌者整理时只发送不含身份、牌面或顺序的短暂整理提示。

## 规则修复

求桃按行动顺序逐席重新检查实体桃、自救酒、急救、储牌、蛊惑与选定版本的涅槃等入口，并应用禁用与完杀；无来源不弹空窗口、不公开跳过名单。自己显示自救，其余显示救援对象。使用一桃仍未脱离濒死时先重查当前救援者。

铁索：原始属性伤害结算结束后才重置该角色，再开始后续连环；濒死、死亡及插入技能先完成。后续角色各自检查防具和伤害防止；不重复原酒、裸衣或武器增伤。保留来源、性质、原卡、材料与使用关联；普通伤害和失去体力不触发连环。金属环视觉与短暂传导演出只是展示，不决定规则状态。

火攻展示花色取展示者的当前有效花色，弃牌匹配取支付者的当前有效花色，兼容双方红颜；非法支付整体回滚。五谷保持逐对象无懈，选得的新无懈可反制下一对象；万箭保持逐人响应，不能抢先提交后位响应。未把规则集旧武将示例直接覆盖到本项目版本。

木牛储牌也可用于合法蛊惑声明；资格判断不看材料真假。取消尚未支付的声明会回到原无懈／求桃窗口。扣置材料保存原来源，在同一结算步骤恢复并立即使用，不投影一次虚假的入手，也不再次触发已经支付过的手牌失去；房主中止时优先退回原木牛容器。规则参照 [官方木牛FAQ](https://www.sanguosha.com/news/20140521_4929_0717)，不将储牌放宽为弃牌费用或拼点牌。

## 同步与存档

schema／protocol8；联机各端需刷新。v1–v7原有技能、装备及手动范围不改变；v7匿名窗口恢复直接就绪，固定映射不重建；缺失的旧记录只用已有数据建立基线。

回合编号包含轮次、技能回合序号与当前席位，旧基础规则桌也不会跨轮复用页面。`turnLedger` 是独立的当前回合展示账本，真实牌只存在于原牌区中。账本随现有本机存档与私密导出保存，回合结束清空；角色近期历史仍有20条／全桌160条的缓存上限。普通投影只携最近32条与总数；经已绑定席位的 `sync` 请求 `{history:{turnId,before}}` 读之前一页，最多32条、64KiB，过期回合及非法页拒绝。收到旧页只合并本回合，控制席、恢复基线或回合变化时清缓存。

记录公开性由发生时材料权限决定。私密材料不依据当前持有者或未来快照补猜；后来真实公开时才更新已有记录。默认仅最新牌有动态作用线，旧牌按需显示静态线，闪与无懈关联前序牌；裁切到不可见的牌不绘制悬空线。

归档事件按出牌人合并，最多三张飞牌加总数；即使本回合超过事件缓存上限，展示总数仍准确。它不产生失牌／得牌、牌区变化或取牌权限。

`flow.drawCompleted` 保存阶段令牌和最早完成时间。Worker只对同一有效阶段串行推进，聊天不重置计时，普通自动偏好不影响已完成摸牌；撤销／纠正／切阶段使旧令牌无效。

匿名窗口保存 `readyAt`；投影另给剩余时长，界面换算本机显示截止，设备时钟不同不会直接解锁。手牌取牌入口检查权威时钟，客户端动画不能提前解锁。`arrangeHand` 走授权action入口，仅当前被抽取者、同窗口同版本可发送，最多每200ms一次，只允许type／id／rev／windowId。提示在Worker的临时容器中，不改变牌区、映射、版本或存档；仍做操作ID去重。网络入口继续仅join／action／sync。
