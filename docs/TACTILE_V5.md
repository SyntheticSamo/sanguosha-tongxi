# v5 · 桌游交互与装备自动结算

本地版本；未推送、未部署公网。武将范围仍为选定的101个版本、190个技能条目；陆抗宝物集智的固定引用口径及实体印次核验限制保留。

## 玩家可见的变化

- 瞄准曲线末端不再反转；只有实际可提交的角色区域显示红色箭头，装备、详情等独立按钮不成为落点。主动技能使用共享验证器；无材料的指向技能进入发动后，可从其技能按钮拖出箭头。点击、多目标编号及键盘操作保留。
- 中央六格阶段条，悬停、聚焦或点按查看阶段和下一步。没有待处理决定时，权威端停留1.5秒再推进；出牌仍手动结束。可暂停、恢复或立即继续；不会替玩家放弃响应、发动技能或选牌。
- 正常摸牌阶段点击抽牌堆，每次一张。英姿、怀橘、庸肆、好施等确定额度；寸目从底部抽取。好施分牌在最后一次摸牌后开始；突袭、裸衣、双雄等替换和独立技能摸牌仍自动执行。
- 起手牌从主公按座次轮流发出，四轮，每张约520ms、发出间隔150ms。实际分配在一个事务内完成，其他人只收到牌背；展示结束后执行开局技能。房主可跳过展示，恢复和重连不重播。
- 公开使用、打出、转化和无实体牌在桌心留只读展示；最新牌指向使用者。回合结束后归档到每人的出牌记录，最新在上；记录不是实际牌区。每人最多20条、全桌最多160条，单个记录缓冲区另限65,536个JSON字符。
- 无懈只有“出／不出”，没有检测手牌后的自动跳过或倒计时。无懈与反无懈保留前序关联，撞击、斜裂、抬起和压下只作用于展示副本，提示抵消的是对某名目标的本次锦囊效果。
- 以本人为参照，距离修正每点最多移动12px，累计限36px；约400ms过渡。武器攻击范围单独提示。空间不足时保留原座位，以精确距离与合法性提示为准。瞄准中冻结位置。
- 动画可选跟随系统、正常、快速或减少动态；教学仍可选。恢复、撤销和重连建立展示基线。

## 装备正常流程不再需要人工执行效果

雌雄双股剑、青龙偃月刀、贯石斧、方天画戟、麒麟弓、寒冰剑接入指定目标、闪后和伤害阶段。可选发动、费用和目标由玩家选择，系统完成实际移动与伤害。方天可叠加天义；青龙在原多目标杀继续前完成追加，支持合法转化、蛊惑及主公激将请求盟友；贯石斧不能弃自身；寒冰依次弃牌，失牌技能在两次之间执行。

木牛以实际装备实例关联独立储牌区，计入守恒。仅当前持有者获得牌面和实体ID，其他人只见数量。支持存牌后可选转交、使用、响应、手牌与储牌混合转化；不能将储牌直接用于弃牌费用、交牌或拼点。装备区之间直接转移保留储牌；离开装备区、死亡或废除宝物栏时自动清理。连营等失牌效果先处理，再进入可选转交。

良姻观察真实专属区与木牛的游戏外移动；桌心和角色旁的展示记录不会触发失牌、获得或游戏外移动效果。房主纠正仍保留在高级工具中。

## 接口及兼容

- schema / protocol 5；不同协议拒绝混用。v1–v4迁移保持原技能范围，设置经典摸牌、推进和原装备范围，不重新发牌；旧v4完整武将技能标记保持。
- 新建界面自动桌启用 `interactionMode=tactile`、`equipmentAutomation=true`；底层创建接口仍允许明确选择经典模式，手动桌不启用新自动行为。
- `drawPhaseCard` 每次固定一张，携带当前摸牌窗口、操作编号与预期rev。重复、过期、他人和超额请求不改变状态。
- Worker内计时任务串行处理，按房间、开局或阶段令牌重新校验；聊天不会重启计时。恢复采用新宽限，不连续追赶过期阶段。网络入口仍限join/action/sync。
- 木牛储牌、展示记录、动画事件均显式投影；扣置蛊惑材料、牌堆顺序、其他手牌和席位token不能通过新字段泄露。

验证结果见 [TESTING.md](TESTING.md)。测试通过不表示所有武将、装备与时机组合均已穷举，也不表示跨互联网或真实手机后台测试通过。
