# 技能自动化支持清单 · v3

2026-10-29。本地工作区，尚未推送或部署。武将文本及来源继续以 `dist/data/generals.js` 和 [版本说明](CATALOG_VERSIONS.md) 为准；支持范围由 `dist/data/skill-support.js` 注册。

101 个武将版本、148 个技能名称、188 种不同技能文本；按每个武将分别计数，共190项技能（同名或同文本不会合并计数）：**148项完整自动路径、5项部分自动、37项人工**。完整路径占77.9%。这是实现范围统计，不是190项全部组合已逐一实战验证的通过率。

新建基础自动牌桌默认开启“扩展技能自动结算”，也可在建桌时关闭。自由手动局不启用。v1/v2旧存档迁移后仍保留原规则，不在局中开启新触发。

- 主动自动：点击技能 → 进入自动发动 → 选择材料、目标及分支 → 确认；系统支付成本和执行效果。
- 触发自动：到达时机时弹出选择；可选技能由对应玩家决定，锁定效果由系统处理。不要再用手动工具重复摸牌、扣血或移动牌。
- 部分自动：仅面板说明的分支由系统执行，其他分支由同桌裁定。决堰的宝物分支会明确拒绝自动发动。
- 困难 · 人工：已标记原因，可使用人工步骤、牌区工具和房主纠正。系统不会伪装成已经执行。

## 已接入的流程

主动支付与目标校验、标准/界版差异、每回合次数与限定标记、伤害后逐点触发、摸牌替换、私看分配和置顶置底、翻面跳过回合、技能拼点与后续、主公向真实盟友请求杀/闪、觉醒后增减技能、牌区废除与距离/次数修正。八阵和八卦判定支持改判后再提供闪；天妒等判定后技能先完成再恢复响应。视为使用的无实体牌不加入牌库，所有牌区仍核对守恒。
