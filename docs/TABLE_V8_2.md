# 第八轮 · v8.2 本地交付

## 桌心与铁索

桌心牌带从固定阶段控件中解开，按当前高度的可用空间展开，避让实际可见角色、装备、判定、响应和牌堆。先重叠再滚动，最小露出半张牌／24px，紧凑卡18px；数量和分页控件移出牌带。当前回合账本、分页和稳定倾斜保留。

点选手牌不画来源或目标线；只有实际瞄准和公开出牌显示关系。删除通用“请选择目标”及空白占位。规则要求、目标顺序和具体错误通过对应控件表达。

铁索先成为本地待用牌，再在角色之间点击或拖线，最后确认提交；取消不扣牌。实体、连环转化、木牛来源及蛊惑／奇策声明走原权威入口。保留一至两名目标、适用的额外目标与重铸。实际横置成功后两端伸链、逐环铺开、扣合、回弹并淡至20%；悬停提亮，传导按实际伤害逐人解除。网络代表全部横置角色，不存永久两人配对；单人使用短链标记。

铁环显式透明填充与细银灰描边；路径使用可见UI矩形的避障图，端口被装备或记录占用时尝试其他侧。链条置于其他UI下方且不拦截输入。横置详情复用角色状态标记。

## 因果演出

PresentationTimeline 管理视觉依赖，TableMotion统一编排飞牌、效果、体力和归档。公开出牌落桌后才播放后续效果；无懈到达前序效果旁后碰撞、斜裂和抬起压下，结束后显露对应记录卡。材料汇合保留手牌／装备／木牛实际来源，无实体牌只显示效果卡。

同一效果按序；批量移牌最多三张同时飞行。开局轮流发牌与不同角色归档可并行，避免把200ms间隔误串成每张等待600ms。五谷铺牌、私看获得和普通摸牌到位前隐藏，动作成功后才显露真实卡面。阶段技能和五谷等可继续操作时，移动中的牌仍保持到位约束。

本人响应窗口及时开放，必要前置演出可快进；数字始终采用权威快照。逐次体力事件带各自前后值，避免连续伤害重复闪同一格。实际结果只播放一套主反馈。操作失败、重连、恢复、撤销和纠正不重播历史。

全部44种牌有独立脚本入口及实际内核场景。刀光、火焰、雷弧、盾面、回复、武器与防具使用不同SVG路径和分段描绘；保留正常、快速、减少动态及战斗特效开关。不使用官方插画、音效、全屏闪烁或黑色遮罩。

## 数据与同步

应用8.2.0，schema／protocol保持8。既有事件增加可选 presentation（id、sequenceId、order、after、effectId、cue），牌使用事件可带经权限过滤的origins；体力事件可带hpBefore／hpAfter，铁索事件带公开chainBefore／chainAfter。

字段有类型、枚举、长度和前序编号约束；投影逐项复制，隐藏材料的origins不发送给无权限者。牌面权限按事件发生时记录。事件仍受64条／32KB限制，缺失依赖建立基线，不等待或补猜。新增数据不构成牌区，不影响牌区守恒与技能触发，不新增网络操作或路由。

演出复核工具只在本机4174运行、复用正式渲染器并使用生成场景；正式网站仍只需静态dist。原101将范围、旧档规则、可选教学和房主纠正保留。
