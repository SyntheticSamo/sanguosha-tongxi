# 本次 101 将数据口径

本项目用户选定：标准 27 + 界标 26 + 神话再临 48，排除神将。`catalog-extension.js` 新增 76 个版本，原有 25 个 ID 保留，另导出 `STANDARD_UPDATES` 对四名原角色做有来源的修订。

核对日期：2026-10-27。

## 名单确定性

- 标准 27 按2013口径：原25加华雄、袁术，不把2023新标准的替换角色再混进来。
- 界标 26 按本次项目约定：原25的界版加界华雄。它不是声称所有历史实体界限突破都只有26：实体2014产品文献还包括李典、徐庶、公孙瓒等人物，部分资料记30张。
- 神话48为风火林山阴雷各8普通将。卧龙与标准诸葛亮是同一人物的独立版本；标准袁术与雷袁术也应有相同baseName，程序据此防止同人物重复上桌。
- 存在不同修订的同名技能，不能仅按技能名将界版、标准版、国战版、移动版效果同时执行。

## 尚未证实最新印次的条目

不要把此数据称为「已逐张核对2026最新黄金大合集」。当前是固定101个角色版本、按可追溯实体包的技能快照；已核验的高风险角色明确标出2013/2017/2018/2020/2022/2024/2025等版次，不能把某一包的最新印次与额外收藏产品、同名线上将混为一谈。没有具名实体节支持的条目保留「身份场参考」与来源说明。目前未取得具体盒装SKU或全套牌面，也不能把尚未逐条复核的普通条目宣称为2026最新实体文本。

UI只需显示包名；版本和来源放在tooltip或资料详情，不必在每张牌面重复此说明。
