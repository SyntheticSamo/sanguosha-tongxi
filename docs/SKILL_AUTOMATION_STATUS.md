# 技能自动结算清单 · v6

新建完整自动桌：101个武将版本、190个按武将计数的技能条目均接入自动效果处理；玩家仍决定发动、材料、目标与分支。游戏无需玩家手动执行这些武将效果。注册表为 dist/data/skill-support.js，文本与来源为 dist/data/；不新增网游武将，不声称采用2026最新印次。

schema / protocol 6。v1–v5存档迁移保留原技能与装备规则；旧v3的148完整、5部分、37人工范围保存在 [历史清单](SKILL_AUTOMATION_V3.md)。新规则不在旧局中强行启用。

## 新增公共机制

- 田、荣、任、创、箜声、扣置牌计入真实牌区守恒；化身池独立于游戏牌。
- 伤害替代、目标转移、封技、不可响应、额外回合、阶段跳过进入权威队列；多步选择可存档恢复。
- 实际牌移动追踪失牌、获得、游戏外移入移出、红牌进入弃牌堆及弃牌阶段来源；不解析日志。
- 蛊惑扣置、化身候选、攻心与审时私看只向决策者发送允许内容。旁观席位不会收到私密分支提示、花色、候选或实体ID。
- 征荣交换、固政归还、烈刃拼点后取得或交换、天香与不屈、神速巧变放权、悲歌、替身、清俭、镇骨等后续均由系统完成。

## 版本引用与范围

2013标准月英集智的交换手牌扣置牌堆顶，同时获得亮出的基本牌；标准版本包含延时锦囊，2020界版限普通锦囊。无懈触发集智后先完成该技能再恢复无懈链。[规则操作定义](https://gltjk.com/sanguosha/rules/glossary/gamecard.html)、[对应月英版本](https://gltjk.com/sanguosha/rules/card/hero/shu.html)。

陆抗决堰宝物栏获得的同名集智，固定采用经典“普通锦囊摸一张”的本桌定义，列于 dist/data/skill-traits.js 的 REFERENCE_SKILLS；其经典定义有规则来源，但尚未独立核验陆抗所选实体印次究竟引用哪一版集智。这个引用口径已在技能详情显示，执行全自动，不留人工结算分支。

v5新建自动桌同时补齐雌雄双股剑、青龙偃月刀、贯石斧、方天画戟、麒麟弓、寒冰剑和木牛流马。玩家选择发动、材料与目标，实际效果自动执行；旧档保留原装备范围。具体交互、储牌限制及兼容见 [v5记录](TACTILE_V5.md)。

## 验证边界

v4新增55项场景检查，保留原108项回归；v5另新增26项，总189项。包括101版本开局、失败回滚、专属区、隐藏信息、封技与转移顺序、真实牌支付、重连恢复。浏览器验证记录见 [TESTING](TESTING.md)。190条注册统计不代表所有多武将、多装备、复合时机的组合均已穷举，也不代表全部实体印次均已逐卡核验。
