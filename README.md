# 同席 · 三国杀

浏览器 P2P 身份牌桌。新建完整自动桌执行基础规则和所选101将的190项武将技能效果；玩家只作发动、材料、目标与分支选择，保留房主纠正。无需自建游戏后端或信令服务器。

## v6 · 卡牌到位显示与桌面效果

手牌在飞到具体位置后显示，手牌带内直接拖动理牌，移出后箭头瞄准。自动／出牌／取消／手动位于手牌正上方。无懈窗口只通知合法反制者和效果接收方，其余席位静默跳过；判定由对应玩家点牌堆翻开，确认后手动继续阶段。

五谷铺牌拾取、顺手／过河背面选牌、两组关系箭头、真实横置铁索网络及回合末记录飞入角色出牌堆。正常流程移除处理区牌堆，内核临时牌区保留。新手教学仍可选。

schema / protocol 6；v1–v5存档保留原技能和装备范围，不补发牌、不重播历史。详见 [v6交付与兼容](docs/EXPERIENCE_V6.md) 和 [验证记录](docs/TESTING.md)。本轮源码发布状态见 [部署说明](docs/DEPLOYMENT.md)。

## v5 · 桌游交互与装备全自动结算（历史）

红色合法瞄准箭头、六格阶段与1.5秒自动推进、点击牌堆逐张摸牌、轮流发起手牌、中央公开出牌与回合末记录归档。六件剩余武器及木牛储牌、转交、响应和转化接入权威队列；无懈只用“出／不出”。新手教学可选。

schema / protocol 5；旧v1–v4档保持原规则，不重新发牌。详见 [v5实现与兼容](docs/TACTILE_V5.md) 和 [验证记录](docs/TESTING.md)。本轮未推送或部署。

## v4 · 完整武将技能结算（历史）

本轮评估14项体验改进，计划及实现见 [完整结算计划](docs/COMPLETE_AUTOMATION_PLAN.md)。新增专属牌区、私密声明与动态化身、伤害替代、阶段跳过、额外回合和跨回合追踪；界面过滤本次可选材料、提示缺少数量，显示转换状态并提供专属牌区详情。新手教学仍可选。

## v3.1 · 整桌布局与卡牌交互（历史）

- 首屏整桌，角色环绕、本人和扇形手牌在下方；本桌/记录/聊天移入下方折叠区域，展开后向下滚动查看。
- 中央回合与阶段操作，右侧抽牌堆/弃牌堆/处理区按数量改变厚度；角色拥有装备与坐骑槽、延时判定区、最近出牌位和判定展示位。
- 箭头瞄准，提交后播放摸牌、出牌、弃牌及判定动画；悬停看规则，特殊牌独立详情及光标倾斜，支持减少动态。
- 人数直接输入2–8的整数，2/3人提醒为非标准局；五选一私密武将牌逐张入场，可跳过。

详细交付及边界见 [v3.1实现记录](docs/SCENE_IMPLEMENTATION.md)。当时schema与协议为3，现已升级为6。本轮仅本地更新。

## v3 · 技能自动化（历史）

- 101个武将版本的190项技能：148项完整自动路径、5项部分自动、37项标记人工；逐版本边界见 [技能支持清单](docs/SKILL_AUTOMATION_STATUS.md)。统计是代码支持范围，不代表所有武将组合已经穷举验证。
- 新建基础自动牌桌默认开启扩展技能；可选触发会等本人决定，主公技能会等盟友实际响应，限定技和次数由系统记录。建桌时可以关闭，旧存档保持原规则。

- 围桌座次、格子体力、距离与合法目标提示；本人固定在下方，手牌跟随本人角色。
- 杀与定向锦囊可拖到玩家框；自用与全体牌可拖到桌心。铁索支持一至两名目标或重铸；借刀按持武器者、被杀者分步确认。点击和键盘操作继续可用。
- 阶段按钮说明下一步；摸牌自动执行一次，新牌标记；弃牌助手显示需要的张数和克己例外。
- 技能注明采用版本与自动化范围。主动技能与转化直接选材料和目标，触发技能进入统一选择窗口；旧局未支持分支保留原人工步骤；新建完整自动桌按统一选择执行。
- 响应区提示出闪、出杀、求桃、改判、拼点等；无懈自动放弃默认关闭，明确勾选后保留三秒撤回时间，切换控制席位后关闭。
- 支持手牌排序、自定义左右移动、长按详情、装备状态、出牌摘要、分类日志和分步联机。
- **新手教学完全可选**：默认不弹出，可随时跳过、退出、重开。局中教学仅显示提示，不覆盖当前牌桌；从首页启动才创建本地教学演练。演练由本人切换席位，没有 AI 对手。

交互及边界详见 [实现记录](docs/UX_IMPLEMENTATION.md)。启动方式和联机方式保持不变。

## 运行

需要 Node.js 22+，无必装第三方依赖。在项目目录的 **PowerShell** 中运行：

```powershell
node scripts/serve.mjs
```

打开 [本地牌桌](http://localhost:4173)。也可执行 `./start.ps1`；Ctrl+C 停止。本机服务只加载静态文件，不传输游戏状态。不能用 `file://` 双击运行模块与 Worker。

在线游玩：[三国杀 · 同席](https://syntheticsamo.github.io/sanguosha-tongxi/)。网站由 GitHub Pages 独立托管，朋友无需 GPT 账号。也可各自本地运行同一版本，再交换邀请。

本地演练顶部有「返回主页」按钮，可随时退出演练，再开新桌或恢复最近存档。

## 建桌和选将

建桌选择人数、结算模式、牌堆和武将包：

- 纯随机：开局分配，每个历史人物最多一人。
- 点将：玩家从启用的武将包选择，所有人选完后开局。
- 五选一：每人获得五个私密候选，选完开局。候选之间不重复历史人物；八人桌需要至少40名独立人物。

收录101个版本：标准27、界标26、神话48（风火林山阴雷各8），排除神将。标准与界版分开存储，同人物的不同版本不能同时上场。技能资料尽量采用可验证的实体身份修订，版本和来源在资料卡详情；未核实的实体最新印次不冒称已核对，见 [版本说明](docs/CATALOG_VERSIONS.md)。

4–8人为标准身份布局；2–3人为自定义身份对抗，不是官方1V1。5人及以上主公体力上限+1。

## 联机

1. 房主建桌，生成邀请，连同网页地址私下发给一位朋友。
2. 朋友粘贴邀请，生成回应，发回房主。
3. 房主接收回应，通道建立后朋友入席。每位朋友分别交换一次。

短房间标识不能独立用于自动加入。默认公共STUN帮助发现公网地址；可在网络选项关闭，完全不联系STUN/TURN。局域网通常可直接连接，公网受NAT和防火墙影响，受限网络可能需要自己的TURN。自定义ICE JSON只留在本次页面内存，不记录凭据。

锦囊无懈窗口默认需要各存活玩家分别响应或放弃。玩家可以主动勾选本席位本局自动放弃，每次保留三秒撤回；未选择时不会自动替玩家决定。杀的闪、决斗的杀须逐张响应；有无双时界面显示还需几张。判定生效前可选择手牌，以鬼才、鬼道或房主纠正改判。

完整自动桌的武将效果已接入系统队列，具体版本、实现口径和验证边界见 [支持清单](docs/SKILL_AUTOMATION_STATUS.md)。木牛储牌与部分装备附加效果仍以卡牌详情为准。旧档保留原范围，请勿重复结算。

## 手动与纠正

目标可以点击中央玩家框选择，再点一次取消；选中会高亮。定向牌也可拖到合法玩家框，单目标松手提交，多目标完成后确认。铁索和借刀先选手牌，再按顺序点击两个玩家，框上显示1、2。点装备或判定牌只选牌，不切换目标。目标选择在当前浏览器保留，其他玩家操作同步时不会清空。

牌桌下方「本桌 → 高级 · 手动裁定」可以补摸、翻牌、调整体力、随机取弃目标手牌。手牌下方「手动」可打出、装备、交牌、弃牌、放入判定区和转化。点击其他玩家装备/判定牌，可移动公开牌。私看牌顶按选择顺序放回，供观星等技能使用。

房主工具：

- 撤销上一步，版本仍递增；已公开的信息无法收回。
- 纠正：中止响应、设置体力/上限、切换目标回合及阶段、横置、重置杀/酒计数、补牌。必须填写原因，记录到公共日志。
- 中止拼点时，隐藏提交牌退还各自持有者；中止其他结算后，桌面牌留给玩家手动处理。
- 自动结算进行时先响应；需要手动改变牌区时由房主先中止，避免破坏待结算事件。

## 存档

房主每次合法变更后将完整状态写入本地IndexedDB，只保留最近主持的一桌。不要同时在同一来源的多个标签页主持。

刷新后恢复牌桌，重新邀请朋友；朋友在原标签页回应，凭保存在sessionStorage的token认领原席位。更换浏览器或丢失凭据不能自动找回。房主离线暂停，不自动迁主。响应队列和未公开拼点也可以恢复。

房主可导出/导入完整JSON，含隐藏牌、身份和token，请私下保管。v1旧存档会迁移为标准牌堆的自由手动局，保持原有牌区。v2存档升级保留原来的基础自动或自由手动规则，不启用扩展技能；v3存档升级到v4时不启用完整技能模式。新存档保存技能选择窗口、私有分配与次数标记；协议为v4，联机双方都需刷新网页。

## 发布与信任

仓库已配置 GitHub Actions：PR 自动检查；启用 Pages 后，合并到 `main` 且检查通过即自动发布。网站和联机不依赖 GPT 托管。配置及迁移步骤见 [部署说明](docs/DEPLOYMENT.md)，多人开发见 [CONTRIBUTING.md](CONTRIBUTING.md)。

将 `dist/` 内全部内容上传任意HTTPS静态托管即可，不需构建或远程游戏后端。`.openai/hosting.json` 只是本次Sites托管元数据，不是运行依赖。

后端位于房主浏览器Worker。普通玩家只收到自己的手牌、隐藏身份和候选，不能看到他人私有区或牌堆顺序。房主拥有完整状态，适合可信好友，未实现针对房主作弊的密码学防护。静态站点可公开，牌局与存档不上传托管服务。网络边界和协议见 [架构文档](docs/ARCHITECTURE.md)。
